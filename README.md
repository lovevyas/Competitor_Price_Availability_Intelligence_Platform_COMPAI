# Competitor_Price_Availability_Intelligence_Platform_COMPAI
A real-time competitor price/availability tracker using public retail APIs (Best Buy, eBay Browse, Digi-Key) with Open Food Facts + Fake Store API fallbacks, ingested via Celery + Celery Beat, stored with CDC/SCD2 in PostgreSQL on RDS, forecast nightly, and narrated by a CrewAI agent crew.
